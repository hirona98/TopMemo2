# TopMemo2

TopMemo2 は Windows 上で動作するシステムトレイ常駐型メモ帳です。
通常時はウィンドウとタスクバーに表示せず、マウスポインタが画面左上のホットコーナーへ入ったときに表示します。

## 主な機能

- システムトレイに常駐します。
- タスクバーに表示しません。
- デフォルト `3px x 3px` の左上ホットコーナーで表示します。
- マウスポインタがホットコーナーまたはウィンドウ上にある間は表示を維持します。
- マウスポインタが外れてから設定時間が経過すると、全タブを保存して非表示にします。
- 背景だけを半透明にし、文字は不透明で描画します。
- 既存テキストファイルをタブで複数開きます。
- アプリ内 UI で対象ファイルを追加、削除、並べ替えます。
- 行頭が `#` の行を太字で表示します。

## 必要環境

- Windows
- .NET 8 SDK

## ビルド

```powershell
dotnet restore
dotnet build
```

## 実行

```powershell
dotnet run
```

設定ファイルは実行ファイルと同じディレクトリの `settings.json` に保存します。
実ファイルのパスはユーザー環境ごとに設定します。
